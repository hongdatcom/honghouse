# honghouse · 1층 전기요금 계산기

101·102·103호의 계량기 차이로 사용량을 계산하고 전체 전기요금을 비례 배분합니다.

## 게시

GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
`index.html`, `app.js`, `github-sync.js`만으로 실행되는 정적 앱입니다.

## 기록 저장

1. 별도의 **비공개 저장소**를 만들고 README를 추가하여 main 브랜치를 생성합니다.
2. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 기록 저장소 하나만 선택하고 Contents: Read and write 권한을 설정합니다.
3. 앱의 GitHub 기록 저장에서 저장소, main, 토큰을 입력하여 연결합니다. 토큰은 채팅으로 보내지 마세요.
4. 계산하고 저장하면 `records.json`에 모든 월의 요금, 지난달·이번 달 계량기, 인사말과 납부기한이 저장되며 수정 이력이 커밋됩니다.

토큰은 현재 페이지 메모리에서만 사용합니다. 새로고침하거나 다른 기기를 사용하면 다시 연결하세요. 저장소 이름과 브랜치만 브라우저에 기억됩니다. 연결하지 않으면 브라우저에만 저장합니다. GitHub 저장 실패는 별도 상태에 표시되며 재시도할 수 있습니다. 다른 기기에서 기록을 수정한 경우 충돌을 감지하여 덮어쓰지 않습니다. 로컬 기록을 백업한 뒤 재연결하여 최신 기록과 비교하세요.

기존 로컬 파일 기록은 기존 화면에서 백업 다운로드 후 게시된 웹 화면에서 백업 불러오기로 옮기고, GitHub에 연결한 뒤 현재 기록 GitHub 저장을 누르세요. 백업 불러오기는 즉시 원격에 저장하지 않으며 별도 저장 버튼을 눌러야 합니다.

## 계산

이번 달 − 지난달 = 사용량. 원 미만은 나머지가 큰 세대 순으로 배분하여 청구액 합계가 전체 요금과 일치합니다. 안내문 단가는 소수 첫째 자리로 표시하며 청구액은 반올림 전 단가로 계산합니다.
